Phase 3: assemble the edit.

Build one edit timeline per output aspect ratio listed in the project settings (create it if it does
not exist; if it exists, clear it first unless the user's instructions say otherwise). Use highlight
(yellow) zones only, preferring higher priority and score, and fit the target duration including the
end card.

Structure the video like a trailer: the strongest shot first as a hook (vertical formats must grab
attention within the first second or two), a build-up of rising intensity, a climax near the end, then
the end card. Match transitions and speed to the mood: cuts on the beat for energetic edits,
crossfades for cinematic ones, slow motion sparingly on peak moments. Vertical formats usually want
shorter shots. Add the game's title as a short title text near the start when the user provided one,
and a call to action on the end card.
